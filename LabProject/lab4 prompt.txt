HTML kısmını projeye dahil etmek için şu adımları izleyebilirsin:

1. Template'in HTML Kodunu Anasayfaya (Index) Dahil Etmek
Pages klasörünün altındaki Index.cshtml dosyasını bul ve aç.

Bulduğun login template'in HTML kodlarını al ve Index.cshtml dosyasındaki mevcut HTML kodlarının yerine yapıştır.

Aşağıdaki gibi bir yapıya dikkat et:

@page
@model IndexModel
@{
    ViewData["Title"] = "Login Page";
}

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>@ViewData["Title"]</title>
    <link rel="stylesheet" href="css/template.css" />
</head>
<body>
    <!-- Buraya Login Template'in HTML kodlarını yapıştır -->
    <script src="js/template.js"></script>
</body>
</html>

2. CSS ve JavaScript Dosyalarını Doğru Yönlendirdiğinden Emin Ol
Template'in CSS ve JavaScript dosyalarının doğru çalıştığından emin olmak için <link> ve <script> etiketlerindeki yolların doğru olduğuna dikkat et. Örneğin:

<link rel="stylesheet" href="/css/template.css">
<script src="/js/template.js"></script>

3. Resim ve Font Dosyalarının Yollarını Kontrol Et
Eğer login ekranı template'inde resim veya fontlar kullanılıyorsa, bunların wwwroot/images veya wwwroot/fonts dizinlerine taşındığından emin ol. HTML'deki bu dosyalara erişim yollarını güncelle:

<img src="/images/background.jpg" alt="Background">
<link rel="stylesheet" href="/fonts/fontawesome.css">
